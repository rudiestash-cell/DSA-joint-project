UG Campus Service Hub – DSA Project

Course

DCIT 204/308 – Data Structures and Algorithms

Project Description

A console-based Java application that demonstrates custom data structures, searching and sorting algorithms, graph algorithms, and database integration using a University of Ghana campus service management context.

Technologies

- Java 17
- SQLite
- GitHub

Folder Structure

- "src/" – Java source code
- "data/" – CSV datasets
- "tests/" – unit tests
- "docs/" – report, attendance, and screenshots
- "performance/" – timing results and graphs

Team Rules

1. Use feature branches for your module.
2. Do not push directly to "main".
3. Commit regularly with meaningful messages.
4. Make sure your code compiles before pushing.
